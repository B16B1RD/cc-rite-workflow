# id の意味を引く対応表は、その id を使う記録と同じファイルに原子的に同梱する

## 概要

記録と、その id が指す候補を別々のタイミングで別ファイルに書くと、途中の失敗で id の対応がずれる。対応表は記録と同じファイルに同梱して一度に書く。持ち越し先の無い値は黙って捨てずに止め、停止の案内を state に書けないときは案内そのものを stderr に出す。

## 詳細

2 つのファイルを別々に書く設計では、片方だけが書けた状態で中断すると、次の読み手が古い候補を新しい記録の id で引く。id を引き直す対応は記録と同じファイルに入れ、1 回の原子的な書き込みで両方を確定させる。持ち越しで写す先が無い値を黙って捨てると、回復経路（合流のやり直し）の後で重複が起きるので、写せない値があれば元の記録を書き換えないまま止める。停止時の案内を state ファイルにだけ書くと、同じ原因（書き込み不能）で案内も失われるため、書けなかったときは stderr に案内そのものを出す。
