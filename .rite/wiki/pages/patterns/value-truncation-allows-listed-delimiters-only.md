# 値の切り詰めは、許す区切り文字を列挙して限定し、rc の振り分けは完全一致で固定する

## 概要

先頭の語だけを値として取り出す切り詰めを「英字以外で切る」と書くと、区切り付きの複合値まで受理してしまう。許す区切り文字を列挙し、切り詰め後の残りが散文の区切りで始まるときに限る。新しい失敗分岐のテストは、rc の完全一致を固定して振り分けを守る。

## 詳細

- **切り詰めの範囲**: 値の後ろに続く文字を「英字以外なら切る」と広く書くと、区切り付きの複合値が通り、本来は規定外として止めるべき値が受理される。許す区切り文字を列挙して限定し、切り詰め後の残りが散文の区切りで始まるときだけ切る。
- **rc の完全一致**: 新しい失敗分岐（再生成を頼む rc=1 と、即停止する rc=2）のテストが rc を「非ゼロ」としか見ないと、振り分けが壊れても通る。分岐ごとに rc を完全一致で固定する。
- **静的スキャナとの相性**: 節の終端を検査する静的スキャナが、awk の `^[...]` 形の正規表現を節終端と誤認することがある。行頭の文字判定は `substr` の比較で書くと避けられる。
