# 値の切り詰めは、許す区切り文字を列挙して限定し、rc の振り分けは完全一致で固定する

## 概要

先頭の語だけを値として取り出す切り詰めを「英字以外で切る」と書くと、区切り付きの複合値まで受理してしまう。一方、値の直後に来てよい区切り文字の列挙だけで判定すると、列挙の外の区切りを取りこぼし、列挙の外の注記を拒否する。複合値かどうかは、区切りと装飾だけを挟んで値の直後に 2 つ目の候補語が来るかで判定する。新しい失敗分岐のテストは rc の完全一致を固定する。

## 詳細

- **切り詰めの範囲**: 値の後ろに続く文字を「英字以外なら切る」と広く書くと、区切り付きの複合値が通り、本来は規定外として止めるべき値が受理される。許す区切り文字を列挙して限定し、切り詰め後の残りが散文の区切りで始まるときだけ切る。
- **rc の完全一致**: 新しい失敗分岐（再生成を頼む rc=1 と、即停止する rc=2）のテストが rc を「非ゼロ」としか見ないと、振り分けが壊れても通る。分岐ごとに rc を完全一致で固定する。
- **静的スキャナとの相性**: 節の終端を検査する静的スキャナが、awk の `^[...]` 形の正規表現を節終端と誤認することがある。行頭の文字判定は `substr` の比較で書くと避けられる。

### 区切りの列挙だけでは収束しない — 判定する位置を「値の直後の候補語」に固定する

- **列挙は両方向に外れる**: 「値の直後に来てよい文字」を列挙する判定は、列挙の外の区切り（空白区切り・装飾付き・読点続き）で複合値を取りこぼし、同時に正しい出力（全角括弧の注記付き）を拒否する。
- **「後ろのどこかに候補語がある」も外れる**: 値の後ろ全体から 2 つ目の候補語を探すと、注記の中の日常語を 2 つ目の値と取り違え、正しい出力を落とす。
- **値の直後に固定する**: 区切り文字と装飾だけを挟んで、値の直後に 2 つ目の候補語が来るときだけ複合値とする。この位置に固定した修正で、過剰な拒否と取りこぼしが同時に解消した。
- **注記の開始記号は条件付きで読み飛ばす**: 括弧のような注記の開始記号を区切りとして無条件に読み飛ばすと、注記の中身を 2 つ目の値と取り違える。読み飛ばすのは、直後の語が接続語のときだけに限る。
- **語を足すなら同じ種類をまとめて足す**: 列挙に語を足すときは、指摘された語だけでなく同じ種類の語をまとめて足して列挙を閉じる。1 件ずつ足すと同じ指摘がレビューのたびに再発する。区切りを足したら、区切りの後ろが候補語でない注記が受理のままであることもテストで固定する。
- **列挙を続けるより値の文法を閉じる**: 読み飛ばす語の列挙は、括弧の内と外で非対称に残りやすい。列挙を増やし続けるより、値として受理する形の文法を閉じるほうが収束する。
- **厳格化は過去の実出力で後退を確かめる**: 判定を厳しくする前に、過去の実出力へ新旧の判定を当てて rc の変化を比べる。正しい出力を落とす後退はここで見つかる。
- **同じ判定への修正が 3 回続いたら位置を決め直す**: 同じ gate への修正が 3 回続いたときは、個別の語を足すのをやめ、判定がどこを見るかを一度決め直す。
