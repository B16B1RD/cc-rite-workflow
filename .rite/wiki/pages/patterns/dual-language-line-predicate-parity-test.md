# 行の受理判定を 2 言語で並行して持つときは、実物同士を行ごとに突き合わせて一致を固定する

## 概要

行の受理判定を Python の正規表現と BRE の sed で並行して持つと、片方だけの編集で判定がずれる。テスト側で helper の定義行を実ファイルから抜き出して実物の sed で評価し、Python 側の実物の正規表現と行ごとに突き合わせる。否定先読みの無い BRE では、行の形と区切り記号の個数を別アドレスに分けて組み合わせると同じ行集合を表せる。

## 詳細

同じ判定を 2 言語で書くと、レビューで等価性を目視確認しても、次の編集で片方だけが変わる。テストは両方の実物を使い、同じ入力行の集合に対する判定結果を突き合わせる。BRE の sed は否定先読みを持たないが、Python 側の `(?:(?!X).)*` は、X が自分自身と重ならない文字列なら、行の形を判定するアドレスと区切り記号の個数を判定するアドレスの組み合わせで同じ行集合になる。等価性が成り立つ文字の範囲（ASCII の空白など）は、テストのコメントに前提として書いておく。
