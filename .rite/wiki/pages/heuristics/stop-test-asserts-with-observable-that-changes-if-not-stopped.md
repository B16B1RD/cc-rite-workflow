# 停止を固定するテストは、止まらなかった場合に観測値が変わる条件で assert する

## 概要

「止まる」ことを固定するテストで、止まらなくても別の理由で同じ観測値になる条件を使うと、停止の分岐を外した変異が生き残る。止まらなかった場合に観測値が変わる条件を用意し、停止分岐を外す変異で落ちることを実際に確かめる。

## 詳細

### 起きたこと

照合に失敗したら起票を止める経路を、「起票が 0 回」で検査していた。ところがテストは判定記録を置かずに実行していたので、止まらずに処理を続ける実装でも、後段の採否ゲートが「判定記録なし」で保留して起票は 0 回になり、観測値が変わらなかった。

### 対処

- 起票の検査には判定記録（採否の出口）を置き、止まらなければ実際に起票される条件で「0 回」を見る。
- 一覧モードは、止まらなければ書かれる一覧ファイルが無いことを見る。
- 停止マーカーの直後で処理を続ける変異を当て、両方の assert が落ちることを確かめてから採る。

### 選言の各項も個別に固定する

「空か `-`」のような選言の判定式は、fixture が片方の値しか使わないと、もう片方の項を落とす変異が生き残る。実データで多数派の値（null）を fixture に入れ、各項を個別に固定する。
