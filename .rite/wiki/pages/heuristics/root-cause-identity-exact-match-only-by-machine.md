# 根因の同一性は機械では一字一句の一致だけを判定し、それ以外は分類役に既存の番号を見せて決めさせる

## 概要

根因が同じかどうかは機械の照合では決めきれない。機械は一字一句一致の再実行だけを受け持ち、言い換えの判定は既存の番号を見せた分類役に任せる。機械側で言い換えを推測する警告を足すと、誤警告と見逃しの両方が出る。

## 詳細

採否が決まるまで外部への起票を保留し、採用した根因だけを起票する変更のレビューで、根因の重複判定が問題になった。同じ根因が cycle ごとに違う言葉で書かれるため、文字列の照合では同一と判定できない。そこで機械側に「似た言い回しなら警告する」規則を足すと、別の根因を同一と誤警告し、言い換えの幅を超えた同一の根因は見逃す。

役割は次のように分ける。

- 機械は、同じ文字列が再び現れた場合（一字一句の一致）だけを同一と判定する。再実行で同じ入力が流れる経路はこれで閉じる
- それ以外の同一性は、分類役（レビューで根因を分類する LLM など）に既存の根因と番号の一覧を見せ、既存の番号を再利用するか新しい番号を振るかを判断させる

同じ対象に振る番号が付け替わりうる記録は、履歴を積み上げず、最新の対応で上書きする対応表にする。積み上げると古い対応と新しい対応が並び、どれが現在の同一性かを読み手が判定し直す必要が出る。
