# 処理量で決まる判定のテストでは、入力の境界と実行時間の上限を分ける

## 概要

入力の処理量が判定を決めるテストを固定ミリ秒で制限すると、CI runner の速度差が機能不良に見える。判定は入力の境界で検証し、時間は実際の実行環境が打ち切る設定上限に収まることを確かめる。

## 詳細

hook の解析予算を調べるテストでは、処理量の境界を越えた入力が期待する判定になることと、hook の timeout に達する前に終了することを別々に確認する。実際の設定値から時間上限を取得すれば、テストだけに置いた固定時間と運用の上限がずれない。設定を読めない場合は原因を表示して停止し、性能測定そのものを目的とするテストとは検証目的を分ける。
