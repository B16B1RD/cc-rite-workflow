# 列挙文の途中へ節を差し込むと後ろの指示語の指す先がずれる — 語を足すより節の順序を戻す

## 概要

列挙の形をした文に節を 1 つ差し込むと、後ろにある「either」「both」「前者」のような指示語が、元の隣接関係を前提にしたまま別の節を指すようになる。語を足して言い換えるより、差し込んだ節を後ろへ回して元の隣接関係を回復するほうが最小の差分で済む。

## 詳細

指示語は、書かれた時点の隣接関係に依存している。「A と B のいずれか（either）」と書いた文の A と B の間に C の節を差し込むと、either は A と C、あるいは C と B を指すように読めてしまう。差し込んだ本人は C を独立した追記のつもりでいるので、後ろの指示語を読み直さない。レビューでは、挿入位置より後ろの指示語が指す先を 1 つずつ確かめると見つかる。

直し方は 2 通りある。指示語を具体的な語に言い換える方法と、節の順序を戻して元の隣接関係を回復する方法である。前者は語が増え、言い換えた語が別の箇所の用語と食い違う新しい指摘を生みやすい。後者は差し込んだ節の位置を動かすだけで、指示語は元の意味に戻る。まず順序の回復を試し、それで意味が通らないときだけ言い換える。
