# 回復経路が「成立しない」判定は、回復側セッションでその分岐が発火するかから辿り直して下す

## 概要

ある経路を「回復不能」「構造的に成立しない」と判定するとき、判定の根拠を**委譲側（不具合を出す側）の記述**だけに置いてはならない。回復側セッションでは同じ分岐に入らないため、共有された状態変数が空でも別経路が正常に働いていることがある。委譲側だけを読んで下した「成立しない」判定は、**機能していた経路を不発の経路へ置き換え、案内文で唯一機能する経路を明示的に否定する**という二重の退行を生む。

## 詳細

### 起点事例: 「回復不能」が誤診断だった

PR #2150 の cycle 1 で、3 名の reviewer（prompt-engineer / tech-writer / test）が独立に次の判定へ到達した。

> 「flow-state に worktree 記録が無い」を委譲モードの発火条件にし、回復手段として「main checkout での再実行」を案内している。しかし再実行時も flow-state は空のままなので同じ検出 helper が同じ結論を返し、委譲した項目に到達しない。

この判定は**誤りだった**。cycle 2 で 2 名が実測により覆した内容は次のとおり:

- 回復側（main checkout での再実行）セッションでは、そもそも**委譲判定が発火しない**。cwd が worktree 内ではないため検出 helper は別の値を返し、通常経路へ進む
- 通常経路のステップ 5 が、削除できなかったブランチを別の manifest エントリ（`branch`）として記録し、既存の age guard バイパスを arm していた
- つまり回復は既存の配線で成立しており、cycle 1 の修正はその配線を不発の記録型へ置き換え、案内文で「その経路は機能しない」と明示的に否定していた

### 判定手順

「回復できない」と書く前に、**回復側セッションの実行経路を最初の分岐から最後まで辿る**:

1. 回復側セッションで、問題の分岐の**発火条件が真になるか**を確認する（発火しないなら、その分岐の欠陥は回復経路に無関係）
2. 発火しないなら、回復側が実際に通る経路を特定し、そこに回復の配線が既に存在するかを読む
3. 存在するなら「回復不能」は偽。存在しないときだけ、新しい担体（manifest / state ファイル）の追加を検討する

発火条件を共有していても、回復側では分岐に入らないために別経路が働くことがある — これが誤診断の構造的な原因である。

### 役割横断の合意は正しさの保証ではない

同一の欠陥に prompt-engineer / tech-writer / test の 3 視点から到達したという事実は、cross-validation として severity boost の根拠になる。しかし本事例は、**3 名全員が同じ誤診断へ到達した**ことを示している。役割が違っても、全員が同じ側（委譲側の記述）だけを読んでいれば結論は同じになる。役割横断の合意は「同じ読み方の共有」でもあり、**実測の代替にはならない**。合意の強さで実測を省略しないこと。

### 「構造的に不可能」という前提も形態を特定して書く

同じ PR で、harness の worktree 隔離ガードについて「構造的に拒否される」と一般化した記述があった。実測すると拒否されるのは **Bash 呼び出しのコマンド文字列に直接 `cd` / `git -C` が現れる形**、および隔離内に留まると検証できない複合ブロックであって、**helper スクリプト内部の `cd` は拒否されない**。

一般化して書くと、自動化可能な操作を恒久的に人手へ委ねる設計判断がそのまま固定される。制約を前提として書くときは、拒否される形態を実測で特定し、その形態だけを書く。

### 同一の配線を語る記述は述語の対象まで揃える

上記の誤診断を正した後も、同じ配線（`recovery=auto` の成立条件）を語る記述が 3 箇所以上に散っており、ある箇所は「`pr_merged=true` のみ」、別の箇所は条件なし、また別の箇所は「`pr_merged` + dirty」と書いていた。読んだ人がどれを根拠にするかで結論が変わる。

粒度を揃える作業では、**述語の対象まで揃える**。「`recovery=auto` になるのは X かつ Y のとき」を別箇所へ「記録は X かつ Y のときのみ」と写した結果、「記録は記録が verify できたときのみ行われる」という自己言及になった。実装では記録は X のみで gate され、Y は recovery の値を決めるだけだった。主語がずれたまま粒度だけ合わせると循環が生まれる。
