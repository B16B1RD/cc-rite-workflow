# レビュー結果: pipefail 下で echo の出力を grep -q へパイプしない（cycle 2）

## 判定

fix-needed（reviewer 2 名、差分スコープ、ブロッキング 1 件）

## 変更の要旨

前 cycle で漏れた `if` / `!` 前置きの echo / printf → grep -q を here-string に置き換え、文書の矛盾と lint の説明を実装に合わせた。

## レビューで得た知見

- 置換対象を検出器（lint）の出力から選ぶと、検出器が例外として扱う形は対象に上がってこない。受入条件が検出器の例外より広い場合（ここでは lint が例外にする `printf '%s' "$var"`）、検出器とは別の、受入条件の文言どおりの検索で残件を確かめる。
- run の途中で Issue 本文を書き換えると、レビューの観測が「仕様が変わった」として拒否される。件数の訂正のような補足は本文ではなくコメントで残す。
