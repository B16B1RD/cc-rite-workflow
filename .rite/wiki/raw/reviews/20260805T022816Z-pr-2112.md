### Finding Patterns

同定手段を「本文照合」から「外部キー (PR body の durable id)」へ移す変更で、6 reviewer が 15 件を検出した。パターンは 3 群に集約される。

1. **read 経路の差し替えで、旧経路が構造的に持っていた不変条件が落ちる**（application + security が cross-validation で独立検出、HIGH）。旧 lookup は `repos/{o}/{r}/issues/{PR}/comments` を列挙するため「当該 PR のコメントである」ことが構造的に保証されていた。新経路 `repos/{o}/{r}/issues/comments/{id}` は repo スコープで issue 非依存のため、author 検証を通しても別 PR/Issue のコメントを PATCH しうる。**同定手段を差し替えるときは、旧手段が明示していない不変条件（スコープ・順序・一意性）を列挙して新手段でも成立するか確認する**のが再発防止策。security は「PR body は書き込み権限を持たない PR 作成者でも編集できる」ことから権限昇格として評価した。

2. **新しい分岐（recreate）が既存の観測機構と交差する箇所で無音の縮退が生まれる**（3 reviewer が別角度から検出）。`recreate` × `list_failed` で degraded=0 になり縮退が completion report に残らない / `recreate` が canonical 実在を無視して重複を作る / `recreate` × `count=0` で収束 cycle のクリアが成立しない。いずれも「新分岐は既存 counter・marker・転記条件のどれとも交差しない」という暗黙の前提が破れた形。**分岐を 1 本足したら、既存の観測 marker の発火条件マトリクスに新分岐の行を足して空欄が無いか確認する**。

3. **テストの identification power 不足が 4 件**（test reviewer が mutation で実測）。fixture が id 経路と fallback 経路を同一結果へ収束させるため T-02 が名目のみ / write 側パス（marker strip・body 読取 guard）が全 TC で未 pin / stub が「rc≠0 かつ非空 stdout」を再現しない。author の mutation matrix M1〜M7 は再現したが、**すべて read 側の判断ロジックに当たっており write 側と stub の忠実性に 1 つも当たっていなかった**。mutation 軸の網羅を「実装の全副作用（read 判断 / write 副作用 / 外部 I/F の error shape）」で設計する。
