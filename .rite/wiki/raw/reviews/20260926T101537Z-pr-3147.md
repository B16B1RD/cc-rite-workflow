### Finding Patterns
- 受入条件は 2 件とも充足。Issue の再現表にある 1 行の形はテストで固定できていた。
- 一方で、同じ欠陥クラス（実行されないかもしれない cd を外側の作業先として確定する）の隣接形が 4 経路残っていた。いずれも実測で、commit 先が別リポジトリと判定されて証跡検査を飛ばすことを確認した:
  - `&&` / `||` / `|` の直後の改行が、先行する演算子を `;` に上書きする（空セグメントでも演算子を記録していた）
  - リスト先頭の `( … )` グループが「リストの先頭」判定を消さず、その後の `&&` 右辺の cd を先頭の cd と誤認する
  - 複合コマンド（if / while / for / { } / case）本体の `;` の後の cd をリストの先頭として扱う
  - `&` で終わってバックグラウンドへ回るリストの先頭 cd を外側の作業先として確定する
