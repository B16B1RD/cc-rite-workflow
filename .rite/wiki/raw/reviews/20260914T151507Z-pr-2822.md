### Finding Patterns
- 明示的 Phase 遷移で駆動する SKILL.md に新ステップを挿入したら、既存の分岐表の行（`process` → ステップ 2）を新ステップへ付け替える。新ステップ冒頭の前提文だけでは機械レールとして辿る実行者に到達しない。
- 再開先スキルの前提条件（`/rite:ready` の E2E whitelist が review / fix のみ、既 Ready の PR では sentinel を出さない）を確認せずに phase → スキルを対応付けると、再開しても同じ段で再停止する。phase=ready は「ready 完了済み」なので次段（merge）へ振る。
- `flow-state.sh get` は JSON パース失敗でも default を返して rc=0 で戻るため、「読み出し失敗 → 停止」を実装するには `flow-state.sh path` のファイルを `jq -e .` で直接検査する必要がある。
- Markdown 表から列を awk で抽出するときは既定 FS で `$1` が行頭パイプになる。抽出直後に非空 pin を置かないと、空集合ループで常時 PASS する pin になる。
- 静的 pin の needle は対象行に固有の文字列にする。同じ言い回しが別ステップにもあると、対象行を戻しても pass する。
