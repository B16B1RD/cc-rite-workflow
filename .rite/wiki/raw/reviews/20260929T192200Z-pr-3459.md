### Finding Patterns
- 冪等化の key を「前の run が残した状態」から作ると、同じ bash がその状態を今回の入力で書き直すため、次の run では材料が変わり key も変わる。再実行 1 回では一致しても 2 回目で崩れるので、key を毎回作り直さず、一度作った key を run をまたいで持ち越す。
- 冪等性のテストは再実行 1 回分だけでなく、状態を消さずに 3 回連続で実行して 2 回目と 3 回目の一致まで固定する。テスト helper が呼び出しごとに状態を消すと、run をまたぐ状態の増加を観測できない。
- 「初回の処分」を「hold が無い」と同一視すると、ゲート保留（held）で残った hold から始まる初回を取りこぼす。
