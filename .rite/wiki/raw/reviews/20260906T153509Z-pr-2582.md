### Finding Patterns

指摘 0 件で終わった差分スコープの cycle。得られたのは reviewer 出力の形式契約と運用面の観察。

1. **指摘 0 件でも出力の形式契約は機械検査される**。`### 指摘事項` を「なし」の散文だけで済ませると、Likelihood-Evidence producer gate が `table_header_missing` で止める。0 件のときも canonical 5 列テーブルのヘッダ 2 行を出すのが正しい形で、「なし」の注記はその下に添える。reviewer への prompt にこの規約を明示しないと、2 名とも同じ形で落ちる。

2. **空入力に対する jq の rc=0 / 無出力は、成功述語を exit status だけで書くと素通りする**。`[ ! -s "$tmp" ]` を述語に足した修正は、空 / 空白のみ / 正常 / 不正 JSON / null の入力で両 reviewer が独立に実測し、空系で fail-loud、正常系で設置、orphan 0 を確認した。同じ `jq > tmp ¦¦ mv` 形の兄弟サイトが他に 2 箇所（fix 1.2.5 の triage state、pr-review 5.3.8 の attribution）残っており、同クラスの点検候補。

3. **reviewer を 1 メッセージで同時 spawn すると spawn spread が確定値になる**。cycle 1〜5 は別メッセージで spawn していたため `undetermined` が続いたが、本 cycle は spread 0 秒で `parallel` と判定された。
