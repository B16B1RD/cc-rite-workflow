### Finding Patterns
- git の出力を解析する helper は、利用者の gitconfig（diff.noprefix / diff.mnemonicPrefix 等）で出力形式が変わる。既存の差分パーサは --src-prefix / --dst-prefix を固定し、その設定をテストで固定している。新しく書いた解析はこの固定を引き継いでいなかった
- 「ファイルとして存在するか」を ls-tree の先頭行だけで判定すると、末尾スラッシュ付きのディレクトリ path が子要素の blob によって通ってしまう。判定と取得は同じ対象（{head}:{path}）を見る形にする
- 前 cycle の fix が足した分岐に、その分岐を外すと落ちるテストが無い（空振りのテスト）ことを、変異で検出された
- テスト網羅性の再掲（生存 mutant）は実測アンカーを持たず non-blocking に留まった
