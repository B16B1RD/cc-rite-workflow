### Finding Patterns
- 新規契約テスト（tests/runtime-e2e.test.sh）の Python heredoc で `pathlib.Path.resolve()` を片辺だけ適用して symlink を比較していたため、`mktemp -d` が symlink 配下（macOS の /var → /private/var）を返す環境で偽陽性 AssertionError となり、本 PR が CI に追加した macOS matrix ステップが恒常失敗した。6 reviewer 全員が同一箇所を独立に検出し、Linux でも TMPDIR を symlink 化して再現できた。教訓: temp dir を基点にパスを比較するテストでは両辺を resolve するか `pwd -P` で TEST_ROOT を正規化する（兄弟 suite tests/rite-dev.test.sh / hooks/tests/host-runtime.test.sh の既存パターン）。
- ubuntu 側の CI 失敗（cleanup-message-contract.test.sh T-09）は PR 変更ファイル外・ローカル PASS・develop 直近 success で flaky と判定し、blocking にしなかった。
