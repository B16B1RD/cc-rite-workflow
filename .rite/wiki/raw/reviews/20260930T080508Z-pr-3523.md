### Finding Patterns
- `git ls-files -s` の出力を行単位で読んで path を取り出すと、`"`・`\`・制御文字を含む path は C 形式で引用されたまま渡る。`core.quotePath=false` が解除するのは非 ASCII の引用だけ。path を後続コマンドへ渡すときは `-z` の NUL 区切りで読む。
- `git update-index --force-remove` は対象の entry が無くても rc=0 を返す。「外せたこと」は終了コードではなく、index を読み直して確かめる。
- signal trap と EXIT trap が同じ cleanup 関数を呼ぶ構成では、cleanup に足した出力つきの処理は 2 回走る。1 回に限る処理はフラグを先に下ろす。
- 追加したエラー分岐のうち、その分岐に入るテストが無いものは変異テストで生存する（検出は security / application の 2 名が独立に再現、test は変異で未固定箇所を列挙）。
