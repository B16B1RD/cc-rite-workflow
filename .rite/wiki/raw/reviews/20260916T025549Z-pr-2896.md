### Finding Patterns
- jq の `//` 演算子は `false` を falsy として右辺へ倒すため、boolean フィールドに `// null` を付けると Ready 判定が常に null になる。boolean を扱う `--jq` 式に alternative 演算子を付けない
- テストのモック gh が `--jq` を無視して固定文字列を返すと、被テストの式が一度も実行されず退行を検出できない。モックはフィクスチャ JSON を実 jq に通す
- hook が helper を絶対パスで呼ぶ場合、PATH 注入モックは効かない。受領ペイロードを観測するには sandbox プラグインルートに記録用モックを置く
- 免除条件を arm の形（`exit 1` の有無・writer の列挙）から推測する静的ガードは、推測の外側に必ず抜け道が残る。免除は明示マーカーで宣言させ、述語を dispatch と marker の 2 値に縮約する
- 不在アサーションは到達マーカーの positive control を先に置かないと、経路未到達でも green になる
- AC の Then に「helper は呼ばれない」が含まれる失敗系は、WARNING トークンだけでなく記録モックの不在で pin する必要がある（fresh run で 3 reviewer が独立検出、class B 降格で non-blocking）
