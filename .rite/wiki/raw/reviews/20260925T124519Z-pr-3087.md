### Finding Patterns
- diff の出力をパースする処理は、ユーザーの git 設定で形が変わる。prefix（mnemonicPrefix / noprefix）、rename 検出、外部 diff、textconv がそれぞれヘッダや本文を変える。パース側で一部の形だけを正規化するより、呼び出し側でオプションを明示して形を固定するほうが漏れない。固定した項目ごとに、その設定を入れた sandbox で結果が変わらないことをテストで押さえる。
- 同じ diff を読む 2 つの走査（削除側と追加側）でヘッダ判定のガードが揃っていないと、内容行がヘッダに誤読される。`-- ` や `++ ` で始まる内容行は diff 上で `--- ` / `+++ ` になる。ヘッダの判定は `diff --git` から最初の `@@` までに限る。
- 除外パスを持つ検出器に「移動の相殺」を足すと、除外パスからの移動が相殺で消える経路ができる。相殺元は除外外パスの削除行に限り、除外パスからの移動を検出するテストを置く。
- テストで `git rm` した直後に同じディレクトリへ書き込むと、ディレクトリが消えて書き込みが失敗し、ケースが空振りで PASS する。rm の後にディレクトリを作り直すか、書き込みの成否を確かめる。
