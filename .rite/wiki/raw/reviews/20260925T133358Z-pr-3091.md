### Finding Patterns
- 設定値を読む sed が行末コメントを落とさないと、値が壊れ、その値を使う git 呼び出しが失敗する。失敗を `|| true` で握って空の結果を照合に回すと、別の拒否理由（evidence_mismatch）に化けて原因が見えなくなる。取得失敗は理由を分けて止め、失敗した値と外部コマンドのエラーをそのまま示す。
- 取得失敗で止める範囲は、その結果を実際に使う判定に限る。全体を止めると、既定値のブランチが存在しない構成（main ベースで設定なし）で無関係な経路まで止まる。止める範囲を限定したら、「止めない側」のケース（使わない経路で失敗しても通る）もテストで固定する。
- 診断のために外部コマンドを再実行すると、失敗した側を再現できない（全文の diff だけが失敗し、名前一覧の再実行は成功する）。診断は元の実行の stderr を保持して出す。
- 固定文字列のエラー照合は、失敗の仕方が 2 経路で同じになる fixture では修正と巻き戻しを区別しない。直した経路だけが失敗する fixture（片方の git 呼び出しだけが失敗する）を置いて区別できるかを確かめる。
