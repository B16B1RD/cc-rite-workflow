### Finding Patterns
- 貼り付け用の手動復旧コマンドへ `printf %q` した値を埋め込む修正は、実 git fixture + PATH 上の git スタブ（checkout-back だけ失敗）+ pre-commit hook（commit 失敗）で到達させ、案内を `eval "set -- …"` で分割して語数・各語を完全一致で固定するテストが mutation に強い（行単位の差し戻しを個別に検出）。
- 「案内を実行して復旧できる」ことの assert は、失敗した commit の index が checkout で作業ブランチへ持ち越されるため、手順 2（cp）を実行しなくても満たされうる。復元系の e2e assert は、前段の手順だけで満たされないか negative control で確かめる。
- %q の代わりに二重引用符で囲む退行は、空白・アポストロフィ・glob だけの fixture では検出できない。`$` やバッククォートを含む値を 1 ケース足すと区別できる。
- 既存の staging 保全時の復旧手順 1)〜3) は、raw source を dev 側 index に staged のまま残し、次回実行で tracked-file の invariant チェックに止められる（別 Issue 相当の既存欠陥）。
