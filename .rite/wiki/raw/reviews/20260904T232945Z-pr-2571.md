### Finding Patterns
helper へ判定を委譲する変更で、委譲元の全経路（Priority 0/2 / Priority 3 / Priority 1 会話経路）を洗い出さないと、一部経路だけ旧来の LLM 裁量に残る。1 本化を謳う変更では「helper を呼ぶ call site の集合」と「その判定が必要な経路の集合」を突き合わせること。
移送先を tempfile にすると、その tempfile を作った呼び出し側が直後に削除する経路では記録が消える。永続化先の実在を経路ごとに確認する。
`if ! var=$(cmd); then rc=$?` は否定で反転した rc を拾い常に 0 になる。同一ファイル内で正しい `else rc=$?` 形式と混在させない。
SoT を書き換える変更では、その SoT を名指しで引用している他ファイルを grep して同期する。片方向の subset 検査しかない drift テストは doc 側の余剰エントリを検出しない。
新規 assert が対象分岐に到達しない fixture で書かれると恒真になる。pass メッセージが名乗る被覆と実際に到達する分岐を突き合わせる。
