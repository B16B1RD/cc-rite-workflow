### Finding Patterns
- bash テストで見出しを `grep -nxF` の行番号に解決し awk へ `NR == n` の整数だけ渡す修正は、gawk / mawk / macOS awk のすべてで同じ行に一致した（CI macOS leg で実機確認）。文字列比較を awk に持ち込まず、比較は bash/grep のバイト比較に寄せると、ロケール依存の `strcoll` 経路を構造的に外せる。
- テストヘルパーが `fail` を呼ぶときは `$(...)` サブシェルの外で呼ぶ。行番号の解決（fail し得る）と本文抽出（fail しない）を別関数に分け、前者をトップレベルで実行してグローバル変数で受け渡す形にすると、失敗カウンタが失われない。
- cycle 2+ の差分スコープで前 cycle の非実測指摘が fix diff に触れられていない場合、finder は「未変更」を確認したうえで記録を持ち越す。sweep は最新 JSON だけを読むため、持ち越さないと指摘が無音で消える。
