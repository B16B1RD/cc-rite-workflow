### Finding Patterns
- 利用者の gitconfig で git diff の出力が変わるクラスを flag の列挙で塞ぐと、隣接する設定が残りやすい。-U0 でも diff.interHunkContext があると近接 hunk が未変更行ごと結合され、hunk 範囲を変更行とみなす解析が未変更行を受理する。--inter-hunk-context=0 を固定し、設定を与えた fixture で hunk 間の行が拒否されることを固定する
- diff.mnemonicPrefix は index / 作業ツリーとの比較でだけ接頭辞を変え、commit 同士の A...B では a/ b/ のまま。この設定を与える回帰ケースは commit 間差分では何も区別しない
- 追加した git 引数（--no-textconv）を外しても通るテストは、その引数の意図を固定していない（変異で検出）
