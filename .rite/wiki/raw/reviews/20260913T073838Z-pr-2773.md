### Finding Patterns
- 下流 awk が終端行で exit し、上流の関数/コマンド出力（4KB 単位で複数回 write する gawk）が SIGPIPE を受ける。`set -euo pipefail` 下では rc=141 でテストが途中終了する。合計サイズが 64KB 未満でも起き、並列負荷下で再現しやすい（16 並列 200 回中 53 回）。
- 対処は下流 awk を `done { next }` 先頭ルール + 終端で `done=1; next` にして入力を読み切る形。ルール順を誤ると終端後も print される。
- 発生条件の説明は「reader が writer の最後の write より前に終了すること」であり、終端行が何番目の chunk にあるかは関係ない（文書精度の指摘、class B 降格）。
- mawk では再現せず gawk で再現。実装差・タイミング依存。
