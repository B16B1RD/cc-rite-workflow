### Finding Patterns
- テスト内で gh mock を事後パッチする `sed -i`（拡張子なし）は GNU sed 専用で、BSD sed（macOS CI leg）では `-i` の引数解釈が変わり suite 全体が abort する。テストファイルでの sed in-place 編集は可搬形 `sed -i.bak` か、mock 定義に直接 marker を書く形にする。
- absence assert（「marker が無い = 到達しなかった」）の precondition（marker の設置）が事後パッチに依存すると、パッチが no-match でも rc=0 のため vacuous pass の経路が生まれる。設置の positive control か、mock 定義内での無条件設置で担保する。
- 文書同期 3 ファイル（Status role の判定箇所 / `todo` のみ受理 / resolver 経路）はすべて実装と一致（3 reviewer 一致）。
- 追加テスト 3 件は Issue が名指しした変異（literal 比較への退行 / `exit 0` 欠落 / guard 行消失）を隔離 worktree の mutation で全件検出。
