### Finding Patterns
- シェルコマンドを字句解析する guard で、二重引用符の中のコマンド置換 `"$(…)"` を抜けた後の引用符状態を復元しないと、よく使われる `cd "$(git rev-parse --show-toplevel)" && git push` が素通りし、逆に文字列内の `;` を区切りと誤認する。置換の入れ子はスタックで追う必要がある。
- PreToolUse hook に 1 文字ずつの `${var:i:1}` 走査を足すと UTF-8 ロケールで二乗時間になり、既存の入力長上限（timeout 内に判定を終える前提）より小さい入力で timeout → fail-open になる。新しい走査を入れるときは、既存の上限が前提にする処理時間を実測し、走査側にも O(1) の fail-closed 上限を置く。
- 文書が「他の層が担う」と書くときは、その層が実際に検出する軸（branch 名・stash・tracked status 等）と照合する。push や tree を汚さない commit は事後ドリフト検出の対象外。
