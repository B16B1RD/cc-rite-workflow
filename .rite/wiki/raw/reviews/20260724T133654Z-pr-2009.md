### Finding Patterns
CI の lint ジョブを informational から blocking gate へ昇格する際の観点: (1) gate は集計値の jq パースではなく lint ツール自身の exit code を採用すると invocation 失敗も fail-loud にできる（silent pass 回避）。(2) blocking 化した lint ツールをバージョン非固定（runner プリインストール版）のままにすると、runner イメージ更新で未変更コードが CI ブロックされうる（Hypothetical、受容 or pin で対処）。(3) source 専用 shell lib の SC2148 は shebang でも `# shellcheck shell=bash` directive でも解消可（既存慣習は shebang 側）。(4) `# shellcheck source=` directive 末尾に散文を書くと SC1125（別行コメントへ分離）。
