### Finding Patterns
- 判定ロジックを literal 条件から関数へ抽出すると、base で「literal = 分岐条件」だった構造的保証が「述語 → 戻り値 → marker」の多段に分かれ、source-grep pin は述語段しか固定できなくなる。抽出時は emit 段の runtime テストを同時に足す（`return 0`→`return 1` 変異が検出されるか）。
- character device の fixture は mknod 不要 — `ln -s /dev/null <path>` で `test -c` が真になる（symlink を辿る）。「非 root で張れない」前提で source pin に逃げない。
- bind mount 判定は `/proc/self/mountinfo` field 5 の完全一致が一次。`mountpoint -q` は util-linux の版で非 mountpoint の通常ファイルの rc が 1/32 で揺れ、mountinfo 不在時は st_dev 比較へ内部 fallback するため bind mount を検知できない。`stat` の st_dev 比較も bind mount と親が同じデバイス番号で判別不能。
- awk へ `\040` を含む照合値を渡すときは `-v` ではなく `ENVIRON` を使う（`-v` は C 風エスケープを解釈して `\040` を空白へ戻す）。
