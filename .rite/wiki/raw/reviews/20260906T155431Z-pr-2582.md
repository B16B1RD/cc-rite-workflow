### Finding Patterns

macOS CI の allowed failure に隠れていたテストの移植性欠陥を、マージ直前の CI ゲートが露出させた cycle。

1. **review↔fix ループは CI を見ない**。`continue-on-error: true` の macOS job は workflow を success にするが PR は UNSTABLE になり、rite のマージゲートだけが止める。テストが PR の初回 push から macOS で落ちていたのに、6 cycle のレビューは一度も CI 結果を参照しなかった。CI の check 結果を review の実測入力に含める経路が無い。

2. **GNU `sed -i '<expr>' file` は BSD sed で「fixture を書き換えない」形で失敗する**。`-i` の次引数を backup 拡張子と解釈し、ファイル名を script として parse error にする。`set -e` が無いテストでは無言で先へ進み、fixture 不変 → diff 空 → 突合系 assertion だけが落ちる署名になる。本リポジトリでは awk read→transform→write→mv が既定で、helper が 4 スイートに別名で複製されている（`_test-helpers.sh` への 1 本化が次の再発防止）。

3. **移植性修正の検証は 3 実装で行う**。gawk / mawk（ローカル）と bwk awk（macOS CI）で同じ 51/51 を得て初めて「直った」と言える。reviewer は no-op 変異で書き換えが load-bearing であることも確認した。
