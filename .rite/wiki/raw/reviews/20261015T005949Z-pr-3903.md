- **Type**: review

### Finding Patterns
- md 内の fenced bash で、全角括弧など多バイト文字の直前に brace なしの変数展開（`（$var）`）を置くと、macOS の bash（UTF-8 ctype が先頭バイトを英数字扱い）で変数名に取り込まれ、展開が空になって化けたバイトが残る。Linux（glibc）では再現しないため、ローカルのテストが通っても macOS の CI だけで落ちる。既存の TC-8b-h の静的ガードは `*.sh` しか走査しないので、md 内の bash は検出範囲の外
- 新しく足したテストの判定を `printf ... | grep -q` で書くと、リポジトリ全体の pipefail-grep-q 検査が全体走査で拾い、別テストが赤になる。here-string（`grep -q ... <<< "$out"`）で書く
- テスト用の偽 gh が `--json` のフィールド指定を無視して全フィールドを返すと、本番で必要なフィールドを取らなくなる変異をテストが見逃す。stub は絞り込みフラグを守る
- 「件数上限を外した」ことを固定するには、上限を超える件数の候補を fixture に置き、本物の親を最後に置く必要がある（旧構文の不在 grep だけでは上限の再導入を検出できない）
- レビュアーの検証実験で作るスタブが `"$0" "$@"` で自分自身を呼ぶと無限に増殖し、開発機ごと落ちうる（別 Issue で手順化）
