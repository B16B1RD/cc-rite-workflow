### Finding Patterns
- skill の手順に新しい実行ブロックを足すとき、その skill のシェルブロック形の契約（helper を介した top-level の単一 bash 呼び出し）に合わせないと、形状契約のテストと CI が落ち、worktree 隔離のセッションではホストのガードに拒否される。fix 側のローカル検証が scripts/tests だけで hooks/tests を含まなかったため、CI で初めて見つかった。手順書を変える修正では、その skill の形状テストを含む hooks のスイートも検証に入れる。
- 成功時だけ marker を出す `cmd && echo marker` は、失敗時に何も残さず、後段の判定表で「何もしなかった」と区別できない。失敗側の marker と fatal 行を対で置く（fail-loud）。
- 判定表の条件を足したとき、同じ規則を言い換えた要約の散文（handoff 文、iterate 判定メモ、「上記 N マーカー」）も同時に直さないと、字面の矛盾が残る。
- PR 本文の実装説明は、helper が実際に集める事実の範囲に合わせる（検証エージェントが手順で補う部分を helper の機能として書かない）。
