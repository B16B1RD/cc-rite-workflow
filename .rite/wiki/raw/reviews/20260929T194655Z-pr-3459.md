### Finding Patterns
- 冪等化の key を run をまたいで持ち越すと、記録の単位の変化が 2 方向で起きる。「別々の key を 1 記録に束ねる」だけを止めても、「1 つの key を複数記録に分ける」を止めないと、2 件目が書き込み済みと誤判定され黙って欠落する。単位の不変条件は両方向で fail-loud にする。
- 機械が止まる規則（束ねてはいけない単位）は、記録を書く側の手順にも同じ語彙で書く。stderr にだけある規則は、止まった run が書いた記録から再開する手順と組み合わさると、同じ停止を繰り返して回復経路が無くなる。
- 持ち越した状態を読むテストは、「新しく作った値」だけでなく「既存の値を継いだ要素も保存される」ことまで固定しないと、保存範囲を狭める変異が生き残る。
