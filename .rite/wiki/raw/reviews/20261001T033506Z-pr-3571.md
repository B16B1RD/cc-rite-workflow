### Finding Patterns
- git hash-object <path> は symlink をたどってリンク先の内容を hash するが、index に入る symlink の blob はリンク文字列。作業ツリーを hash して index と比べる照合は、symlink で必ず食い違う。作業ツリー側の hash は symlink ならリンク文字列で取る（git が index に入れる値と同じ）。
- 前提「git add 後は作業ツリーの hash と staged の値が等しい」は通常ファイルでしか成り立たない。手順書がこの前提を書いたら、symlink と実行ビットなど git の表現が作業ツリーと異なる種類を洗う。
