### Finding Patterns
- git stash を挟む失敗経路の cleanup で index を操作するとき、stash pop の後に path 単位の reset を行うと、stash pop が index へ戻したユーザーの staged エントリまで巻き込む。index の後始末は stash pop より前（持ち帰ったエントリだけが index にある時点）に行い、手動復旧手順と自動経路の順序を一致させる。
- index 操作の範囲（pathspec）を守っていることは、無関係な staged ファイルを置いた fixture でしか検出できない。clean な fixture では「index 全体 reset」への退行が green のまま生存する。
- 失敗後の分岐（unstage 失敗など）で「処理を継続する」ことは、その分岐専用ケースで後続の INFO 行等を assert しないと mutation が生存する。
