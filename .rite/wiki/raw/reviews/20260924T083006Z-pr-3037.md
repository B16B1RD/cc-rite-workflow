# レビュー結果: Wiki 適用証跡ゲートが未知の --mode を拒否する（cycle 1）

## 判定

fix-needed（reviewer 2 名、XS/S 軽量レーン、ブロッキング 1 件）

## 変更の要旨

gate の --mode を commit / review に限定し、未知の値は受理値を示して止める。review の blob 照合と省略時の既定をテストで固定した。

## レビューで得た知見

- 「既定値が X であること」をテストするときは、X と他の値で結果が分かれる入力を使う。どの値でも同じ結果になる fixture では、既定値を変える変異が生き残る。ここでは同一セッションの記録を使ったため、commit も review も同じ stale_content で拒否され、既定の区別ができなかった。
- 入力値を検証して取りうる値を狭めると、以前は区別が必要だった分岐の書き換え（否定条件 → 肯定条件）が等価変異になる。変異が生き残っても、入力検証で等価になったのか、テストが見落としているのかを分けて判断する。
