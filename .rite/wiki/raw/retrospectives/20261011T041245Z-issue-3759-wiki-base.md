### Wiki 独立履歴の進捗同期に残る実装不足

現行 post-tool-wm-sync.sh は main の rite-config branch.base=develop を固定して origin/develop...HEAD を取る。承認済み Wiki base の作業ブランチと develop には共通祖先がなく、明示 checkpoint は失敗し last_synced_phase を前進しない。phase 改竄・ref 付け替え・main設定変更で成功を補完しない。

必要な別実装の一行案: `_base_branch` の既存 config 解決に `WM_BASE_BRANCH_OVERRIDE` の呼出し時指定を優先する。unset/empty は既存の config→origin/HEAD fallback を維持し、未知 base は既存 git diff エラーのまま。新しい常設設定・台帳を追加しない。

一時コピーのみで、既存 post-tool-wm-sync.test.sh の setup/GET/PATCH shim と実 Git を使用して独立履歴の fixture を作り、実 hook 全体を explicit で試した。GitHub API は shim、共有 state と main plugin/設定は未変更。

正常 develop: 元版 rc0/同期implement、修正版 unset rc0/同期implement、修正版 empty rc0/同期implement。Wiki orphan: 元版 override=wiki でも rc1/同期init（共通祖先なし）、修正版 wiki rc0/同期implement。未知 base: 修正版 rc1/同期init。全6ケースの config は branch.base develop のまま。状態の成功を手編集せず、hook 自身の更新を測定した。

初回は既存 fixture の local WM が単なる文字列で phase parser rc2 fallback warning を出した。初回結果は initial-corrupt-local-wm-* に保持。正しい local WM frontmatter を与えた再測定では、この無関係な warning はなく、上記6結果は同じだった。

証拠: /tmp/rite-3759-wm-base-proposal/post-tool-wm-sync.patch、results.json、driver.out、hooks/tests/wm-base-proposal-driver.sh。これは検証済み修正案であり、tracked実装・レビュー・runtimeへの採用は未実施。親棚卸しPRにplugin変更を混ぜず、必要な別作業として昇格候補消化経路へ接続する。
