### Fix Patterns

1. **glob で集合を指すと、集合の増減に silent に追随しない**

   「本文検査 4 段」を `reason=body_*` という glob で指した結果、(a) glob に合わない要素
   (`count_body_mismatch`) を最初から取りこぼし、(b) 後から増えた別集合の要素
   (`body_check_unavailable`) を誤って拾った。**命名規則と集合の境界は独立に変化する** —
   診断・分岐の述語には glob ではなく明示列挙を使い、列挙には「対象外」も書く。

2. **hint / 診断関数は「原因の類型」ごとに分ける — 便利な既存関数の転用は誤案内になる**

   環境起因の新経路に、文面がそれらしい既存の gh/IO hint を転用した結果、「gh auth を確認せよ」と
   「gh の問題ではない」が同一ブロックに同居した。復旧案内は原因分類と 1:1 で対応させ、
   テストでは「正しい案内が出る」と「誤った案内が出ない」の両方向を pin する。

3. **一時ファイルは生成した瞬間に trap 保護下へ置く**

   生成 → 使用 → 回収変数への代入、の順だと生成〜代入の間に signal を受けたファイルが漏れる。
   代入を生成直後に前倒しするだけで窓が閉じる。signal-timing テストは本質的に racy なので、
   「代入行が使用行より前にある」ことの順序静的 pin で代替できる。

4. **「日本語がそのまま出る」の pin は「無害化を丸ごと外す」退行を検出できない**

   素通しでも日本語はそのまま出るため、pin は「フラグが honor されている」ことしか固定しない。
   無害化の存在自体を pin するには、**無害化されるべき入力** (ESC 等の C0) が実際に `?` 化される
   ことを assert する必要がある。positive (通るべきものが通る) と negative (潰されるべきものが
   潰される) は別の pin。

5. **rationale リンクの原本を先に直す — リンクは伝播を肩代わりしない**

   本体 (SKILL.md) に carve-out を足しても、その行が `rationale:` として名指しする参照先が
   旧規則のままなら、参照先を読んだ agent は旧規則を採る。リンクは「参照先が正しい」ことを
   前提にした委譲であり、述語を変えたら**参照先から先に**更新する。

6. **機械的な文字列置換はコメントの意味を反転させうる**

   「旧版は X で、Y を検出できなかった」の前半だけを「本 pin が満たすべき条件: X」へ置換した
   結果、棄却された手法 X を要件として宣言する文になった。ジャーナルコメントを不変条件記述へ
   書き直すときは、**文全体を書き直す** (接頭辞の差し替えでは主述の対応が壊れる)。
