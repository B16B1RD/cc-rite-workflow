### Fix Patterns
- 単一パスを照合する git コマンド（ls-files / rm / add）は pathspec の glob 解釈を受ける。`[id].tsx` のようなパスでは `:(literal)` を付けないと兄弟に一致する。テストの準備側（git rm）も同じ罠にかかるので、glob 文字を含むパスのテストでは準備にも `:(literal)` を使う。
- テストの in-place 編集は `sed -i.bak` に揃え、前提を作った直後にその前提が成立していることを assert すると、環境差で空振りしない。
