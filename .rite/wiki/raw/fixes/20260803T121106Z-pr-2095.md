cycle 3。収束局面 (blocking 推移 1 → 3 → 1) で観測されたパターン。

1. **文書側の自己言及回避と「記入形式の指定」を混同させない**: Gate 文書が自分自身の検出を避けるために書式を崩している場合、その崩した形が読者には「こう書け」と読める。退避である旨と正しい記入形式を必ず併記する。本 PR では全角矢印がこれに該当し、模倣すると指摘が降格して Gate 自身の受入基準が破れていた。

3. **教材例に実在ファイルを名指ししない**: Gate が「判別に迷ったら repro を実行して観測せよ」と指示する以上、教材例は必ず検証される。実在ファイルを挙げた例が事実と食い違うと、教材の信頼性が Gate の運用精度に直結して落ちる。抽象例にすれば陳腐化もしない。
