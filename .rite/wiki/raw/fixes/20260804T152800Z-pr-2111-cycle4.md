## 適用した修正パターン

- **形状 gate は閉じた値域限定**: placeholder residue gate を形状ヒューリスティック (brace 囲み) から literal exact 突合 (`{title}` 等) へ変更。free text へ形状判定を適用すると正当値を棄却する。呼び出し側が未置換時に literal をそのまま渡す構造なら exact 突合が必要十分。
- **marker は結果を表現し試行を表現しない**: 統計同期の marker が「試みた」ことしか持たず 0 行同期でも synced を返していた。同期できた行数を数え、0 なら既存 enum (skipped_unreadable = 前サイクル値のまま) へ降ろす。enum を増やさず意味の一致する既存値に載せることで表・docstring を無改変で済ませた。
- **位置抽出の暗黙前提を検査に変える**: 捨てるフラグメントが空白のみであることを検査し、違反は既存の fail-loud 経路 (awk stderr ERROR + 非ゼロ exit → row-rewrite-failed) に載せた。新しいエラー分類を発明せず既存契約へ相乗りする。
- **文書アサーションは形を固定する**: 継続行コマンドの契約テストは行断片の列挙ではなく、継続行を join した 1 論理コマンドへ正規化して全フラグの同居を assert する。断片列挙は増やすほど保守が重くなるのに変異耐性が上がらない。
- **復旧手順は帰責先で分ける**: exit code 表で LLM 起因 (substitute 漏れ → 再実行で収束) と環境起因 (lint 委譲) を別行に分割。統合すると再実行 1 回で直る失敗が恒久スキップになる。
