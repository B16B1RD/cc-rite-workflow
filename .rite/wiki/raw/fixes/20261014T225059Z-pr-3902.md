# PR #3902 の修正結果（PR 内推奨 2 件、cycle 5）

- 指摘: Linux 以外でケースを外す枝が echo だけでテスト補助の数える skip() を通らず、SKIP 件数と runner の見出しに出なかった。Linux の判定も既存テストの [ -d /proc ] と違い PATH で探す uname に頼っていた
- 対応: 外す枝を skip() に替え、Linux の判定を [ -d /proc ] にそろえた
- 学び: テストで検査を外すときは、プロジェクトの数える skip() を使う。検査が必ず走るべき環境の判定は、外れる原因と同じ PATH に依存させない
