# PR #3902 の修正結果（PR 内推奨 3 件、cycle 2）

- 指摘: 説明は引用符などを含む名前を生の名前で表示すると書くが、UTF-8 ロケールの gawk では不正なバイトと引用符を両方含む名前が正規表現 `^".*"$` に一致せず、引用形のまま出た。\a \b \f \v の復号の枝はどのテストも通っていなかった
- 対応: 説明に限定を重ねず、走査する awk を LC_ALL=C で動かして挙動を説明に揃えた。テストは特殊な名前の --diff を C.UTF-8 で実行し、不正なバイトの名前と 4 文字の名前を足した
- 学び: awk の正規表現の `.` は UTF-8 ロケールで不正なバイトに一致しない。バイト列を扱う awk は LC_ALL=C で動かす。ロケールを固定すると、別の固定（core.quotePath=false）を外す変異が等価になることがあるので、変異の主張は固定の後に測り直す
