### Fix Patterns
- 前段の高速パス（部分文字列フィルタ）は、後段 helper が追跡する語彙（cd / pushd / popd / chdir / sudo）と同じ集合で除外する。片方だけ拡張すると前段が fail-open の穴になる。
- 共有パーサに情報が足りないとき（サブシェルのグループ境界）は、新パーサを作らず既定 off の任意引数を足して再利用すると既存呼び出し元を壊さない。
- 変数のリテラル追跡は「代入がちょうど 1 回、かつ for / read / export 等で素の語として現れない」名前だけを信用する。数えるのは生テキストではなくパース済みの語（コメント中の名前で誤判定しない）。
- 「リポジトリでない」と「git が読めない」は .git の有無で区別し、後者は fail-loud で拒否する。
- ラッパー（timeout / env / xargs / sudo …）は値を取るオプション表で値を読み飛ばし、env -C / sudo -D は実行ディレクトリの移動として扱う。
