# PR #3902 の修正結果（PR 内推奨 3 件）

- 指摘: 件数の行が欠けたときに exit 2 で止める分岐、8 進と CR の復号の枝を、どのテストも通っていなかった。説明は不正な UTF-8 と引用符を両方含む名前まで生の名前で表示すると書いていた
- 対応: awk の shim で件数の行を落とす・数値でない値に替える 2 ケースと、制御文字と CR を含む名前を足した。説明を実装で成り立つ範囲に限った
- 学び: 出力を加工するツールの shim は、本物に引数と終了コードを素通しし、変えたい部分だけを変える。復号表は枝ごとにそれを通る入力を置く
