# fix 結果: run-tests-accounting の printf から grep -q へのパイプも here-string にする

## 対応した指摘

- test / MEDIUM: lint が例外にする `printf '%s' "$var" | grep -q` が 1 か所残り、受入条件を満たしていなかった

## 修正

停滞診断（作業時間）による見直しで、この PR 内で直す案と別 Issue に残す案を比べ、受入条件の範囲内で 1 行の同種置換で解消できる前者を選んだ。置換に加え、検出器の例外に依らない受入条件どおりの残件検索を検証に登録した。

## 知見

- 検出器の例外に該当する形は、検出器の出力を置換対象の一覧に使うと必ず漏れる。受入条件が検出器の例外より広いときは、受入条件の文言をそのまま検索式にした残件検索を検証に加える。
- 非致命として後続 Issue に送った指摘でも、受入条件の範囲内で小さく直せるなら、見直しの際に PR 内で直す方が Issue を正しく閉じられる。
