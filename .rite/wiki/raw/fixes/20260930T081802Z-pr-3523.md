### Fix Patterns
- git の index から path を読んで別コマンドへ渡す処理は `-z` の NUL 区切りにした。行出力の引用を外す処理を書くより、引用を経由させない方が短く確実。
- 「対象が無くても成功を返す」コマンド（`git update-index --force-remove`）の結果は、破壊的な次の手（`git rm -rf`）の前に index を読み直して確かめる形にした。
- signal trap と EXIT trap が共有する cleanup に足した検査は、同じ cleanup の既存処理と同じ「先にフラグを下ろす」形にそろえた。
- `git -c status.showUntrackedFiles=normal status` の `-c` は submodule 側の status にも届く。`--untracked-files=normal` は親にしか効かない。
- 追加したエラー分岐は、偽 git で 1 分岐ずつ入るテストを同じ修正で足した。変異（フラグ削除・行読み取りへの差し戻し・再確認の無効化）で各テストが落ちることを確かめた。
