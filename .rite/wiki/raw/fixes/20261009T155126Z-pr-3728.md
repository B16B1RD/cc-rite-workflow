### Fix Patterns
- 外部コマンドの出力を解析する helper は、利用者の設定で出力形式が変わる箇所を呼び出し側で固定する（git の core.quotePath・diff の prefix）。--no-ext-diff 等と同じく、形式を変える設定は全部潰す
- 失敗を一律に error として扱わず、「存在しない」（NOT_FOUND）と「取得できない」を分ける。前者は判定材料、後者は判定不能
- 件数上限のある取得は、切れたことを事実に残す（totalCount と比べて truncated の印）。判定側は印のある一覧を否定の根拠にしない
- mock は実際の API と同じ形で答える（GraphQL の NOT_FOUND は JSON 本文 + exit 1。REST の 404 と違う）。fixture が既定の形だけだと、実際の分岐がテストを通らない
- 受理側の正規表現は、生成側の自然な出力と、同じアンカーを受理する既存のゲートの式に揃える
- str.lstrip は接頭辞ではなく文字集合を剥がす
