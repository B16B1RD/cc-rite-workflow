### Fix Patterns
- 読み手の分岐に値を足すときは、その分岐に到達する前段のゲートを、書き込み元が実際に書く state の形で通るか確かめる。停止を書く経路が同じ更新で active=false も書くなら、active=true でしか動かない案内は停止を一度も表示しない。inactive の早期 exit の直前に、停止理由が残る場合だけの案内を置いて直した（state は書き換えない）。
- テストの fixture は書き込み元が同じ更新で書く全フィールドから組む。停止理由だけを置いて active を実在しない値にした fixture は、到達不能な分岐でも green になる。修正では fixture を実形に直して先に red を確認し、停止理由の無い inactive state では何も出さない対照も置いた。
