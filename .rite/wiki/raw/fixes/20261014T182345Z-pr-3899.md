# PR #3899 の修正結果（cycle 1）

- 指摘: 一覧を渡さない capture が git status の既定 -unormal で未追跡ディレクトリを dir/ の 1 件として拾い、hash-object で失敗して base 取り込みの取り直しが止まる
- 対応: capture の status 読みを --untracked-files=all にし、未追跡ディレクトリは中のファイルごとに記録する。手順書の記録範囲の説明と inventory の式を揃え、未追跡ディレクトリのある取り込みのケースをテストに足した
- 学び: 一覧の取得元を別のコマンドへ替える修正では、新しい取得元が返す要素の種類（未追跡・ディレクトリ・改名の片側）を旧取得元と並べ、増えた種類ごとに fixture を置く
