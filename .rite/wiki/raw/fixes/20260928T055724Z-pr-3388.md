### Fix Patterns
- bash の fail-closed な ERR trap 区間から関数を呼ぶときは、呼び出しの間だけ `set -E` を有効にする。関数内に試験専用の失敗注入（if 文の本体で false）を置き、rc=2 の拒否をテストで固定すると、errtrace の外し忘れを検出できる。`&&` の左辺や `||` の左辺に置いた失敗は errexit も ERR trap も起動しないので、注入は if 文の本体に置く。
- bash の case 文のパターンに `esac` や `case` を書くときは引用する（`'esac')`）。引用しないと予約語として case 文の終わりに解釈され、構文エラーになる。
- 字句解析でコマンド置換の閉じを判定するときは、括弧の深さに加えて、コマンドの先頭に置かれた case を esac まで数え、開いている間の `)` を区切りとして扱う。
