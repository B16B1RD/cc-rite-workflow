### Fix Patterns
- 中断からの再開は、処理済み raw の有無だけで完了と判断せず、未 commit の本文・index・log を照合する。保存対象一覧を残し、通常の番号参照検査と commit を経て本文比較へ進む。
- 比較不能は batch の成功判定より先に扱い、cursor を保持してキューを停止する。Issue が閉じていても未完了の cleanup を再開できる。
- 自動検査のログは commit 済み内容を読み戻す。WARNING を出して exit 0 になる helper では終了コードだけを保存成功とみなさない。
- Stop hook 検証では Git 初期化を先に行い、停止前の block と停止後の解除を両方実行する。
