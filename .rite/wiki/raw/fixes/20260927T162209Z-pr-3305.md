### Fix Patterns
- mergeable の cycle で登録された PR 内推奨（文書の主張が実装の判定範囲より広い）を、主張を広げるのではなく実装の判定規則そのものに限定して解消した。
- 文書の主張を直す前に、主張が名指しする入力（`>|` / `2>|` / `{fd}>out` / `<<- EOF` / `<<-EOF` / `3< in`）を実装で列挙して index / other を実測し、例示と例外をその結果から書いた。
- 代表例から規則を一般化して書くと、実装が除外しない形まで主張に含まれる。規則は実装の判定条件（どの語をリダイレクトとみなすか、いつ次の語を先として扱うか）で書く。
