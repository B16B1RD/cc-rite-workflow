- **Type**: fix

### Fix Patterns
- 検査パイプラインの除外フィルタを violations の列にだけ書くと、floor guard が別の母集団を数えるため除外を広げる変異を検出できない。絞り込みを関数 1 つにまとめて violations と floor の両方に通すと、除外の拡大が floor の 0 件として現れる。
- 行範囲を切り出す sed の検出枝は `sed -n` だけでなく `sed -ne` / `sed -n -e` の綴り違いまで拾わないと、書き換え一つで中和漏れが無検出になる。
- 「同じ会話に限る」のような限定は、実行者が確かめられる観測対象（保持しているべき値の名前）を併記し、それを読めなければ続けない、と書くと compaction 後の誤認を防げる。
