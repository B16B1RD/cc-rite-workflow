- **Type**: fix

### Fix Patterns
存在検査しかしない記録に原子書き込みの共通関数を使い、副産物の `.lock` が残った。テストの冪等 pin が 1 秒粒度の時刻の直後の再実行で、ガードを外しても通る形だった。
- 存在検査しかしない記録は mktemp と mv だけで書く。共通の原子書き込み関数は lock ファイルを残す。
- 冪等の pin は、記録や区間の時刻を過去へ書き換えた fixture に対して 2 回目を実行して比べる。直後の再実行を byte 比較するだけでは、時刻が同一秒に収まって検出力が無い。
- 停止許可のような「終了コード 0 が契約」の分岐は、出力が空であることとは別に終了コードを pin する（`|| true` で捨てない）。
- 兄弟機構が持つ失敗経路のテスト（非 object の記録・別セッション指定）は、同じ処理を再実装した側に継承されない。再実装したら失敗経路のテストも揃える。
