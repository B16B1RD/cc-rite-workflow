### Fix Patterns

「A と B は同一母集団」と宣言する対の記述があるとき、片側の述語に disjunct を足すと宣言が偽に
なる。宣言を守るために置かれた pin が両側の共通 prefix までしか張っていないと、乖離しても
緑のまま通り、pin が守ると宣言した不変条件が破れたことをテスト自身が検出できない。述語の
母集団を変える修正では、(1) 対の宣言文、(2) その宣言を張る pin の regex 範囲、の両方を同時に見る。

宣言が偽になったときの直し方は 2 通りある。母集団を揃える（機構を足す）か、宣言を実態の
包含関係へ縮める（記述を狭める）か。後者のほうが差分が小さく、次に片側が広がったときに
再び偽になる面も増えない。

pin を強化するとき、新しい assert を足すより既存 assert の regex を末尾まで伸ばすほうが
機構は増えない。新規 assert が要るのは、既存 assert が見ていない別の対象（宣言文そのものが
消える退行など）を張るときに限る。
