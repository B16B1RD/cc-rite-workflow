### Fix Patterns
- 除外の担保を「親ディレクトリに置く未追跡の .gitignore」で自己完結させたとき、linked worktree の checkout にはそのファイルが存在しない。検査は cwd ではなく state root（main checkout）で行う。同じファイルの別の検査が既に state root を使っていれば、対象を揃える 1 行の変更で済む
- worktree を作る経路が手順書と共有ライブラリの両方にあるときは、除外の書き込みを両方に足す。ライブラリ側は既存の ensure helper を呼ぶ小さな関数にまとめ、成功経路の直後に 2 箇所から呼ぶ
- 手順書の bash ブロックが別ブロックで代入された変数に依存するとき、新しい行は必須変数の検査（`${var:?}`）で空のときの誤書き込みを fail-loud にする
