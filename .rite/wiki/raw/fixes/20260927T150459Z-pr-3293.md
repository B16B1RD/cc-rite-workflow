### Fix Patterns
- 生存判定の入力（現在時刻）が読めない失敗を「古い」と同じ return 1 に倒すと、回収経路の削除が他者の生きた資源を消す。判定に必要な値を取れないときは、判定の前に ERROR で止める（判定関数内で exit する）。時刻を内部で使う parse より先に現在時刻を読むと、壊れた時計が「parse 不能 = 古い」にすり替わらない。
- 同じ ERROR 文に複数の失敗段（時刻取得・書き込み）を束ねると診断できない。段ごとに文面を分け、テストは件数ではなく文面で照合する。
- 手順書の WARNING は「確認できなかった」と「失った」を分け、対処文には設定ごと（branch_strategy）の具体的なコマンドを書く。
