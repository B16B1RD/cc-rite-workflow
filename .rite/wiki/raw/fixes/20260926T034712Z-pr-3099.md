### Fix Patterns
- PreToolUse の commit-target 解析は、commit / merge と同じ Bash 呼び出しに case 文があると ambiguous shell word として解析を諦め deny する。SKILL の commit 手順の未置換ガードは case ではなく if grep で書くと、単一呼び出しのまま解析が通る。
- ゲートを有効化する phase 変更では、同じ phase を条件にする別 hook を通した経路で既存手順を検証する。helper を直接呼ぶテストは hook 経路の退行を検出できないため、SKILL の手順ブロックを抽出して guard に通す assert を足した。
- guard を含むテストは実行者セッションの flow-state を拾うため、セッション ID を隔離して実行しないと環境由来の失敗が出る。
