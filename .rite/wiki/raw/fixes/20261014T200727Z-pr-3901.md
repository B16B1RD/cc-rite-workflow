# PR #3901 の修正結果（PR 内推奨 4 件）

- 指摘: 登録の無い mark が止まることを、テストが登録ファイル欠落の 1 入口しか試していなかった。照合キーに commit_sha が入っていることを区別するテストが無かった（旧形式のケースが直前に入ったため）。done ファイルの説明が pending の条件を新しい根因に限っていた
- 対応: 別 commit の登録・空の登録の 2 入口を足し、渡した推奨と同じ内容を新しい commit に登録し直すケースで pending を固定した。説明を内容の差分での判定に合わせた
- 学び: 照合キーや guard を足したら、キーの各要素・guard の各入口を単独で落とす入力を 1 つずつ置き、その要素だけを外す変異で落ちることを確かめる
