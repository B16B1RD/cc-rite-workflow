### Fix Patterns
- 引数検査の probe は exit code だけでなく stderr の拒否理由まで assert する。exit 2 だけでは、他の必須オプションの不足で止まった場合と区別できず、名乗る挙動（未知オプションの拒否・特定の必須引数）を外しても green のまま残る。必須を持たないサブコマンドか、他の必須を満たした呼び出しで probe する。
- ステップ本体を helper へ移したら、その呼び出し経路を説明する参照記述（仕様書の表・呼ばれる側のヘッダコメント）も追従させる。「直接呼び出される」のような経路の記述が古くなりやすい。
- placeholder を変数へ受けていた行は helper へ移すと自己代入の無効な行になるので、移設時に消す。
