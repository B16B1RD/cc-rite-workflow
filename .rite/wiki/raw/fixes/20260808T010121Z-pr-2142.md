### Fix Patterns

前 cycle の修正が新設した 1 行に指摘 5 件が集中した事例への対応。得られた経験則。

1. **同一行に集中した複数指摘は、パッチを重ねず 1 回の書き換えに統合する**: 述語の誤り・中和の欠落・rc 破棄の 3 件が 1 行に付いた。個別に当てると同じ行へ 3 度手を入れることになり、途中状態のたびに新しいレビュー面が生まれる。前 cycle の fix が導入した箇所への指摘は escalation trigger として扱い、まず「当該機構ごと削除できないか」を検討したうえで、残すなら**統合した 1 回の書き換え**にする。

2. **番人 (probe / assert) は「守る対象」ではなく「探し方」で壊れる**: 静的 denylist の haystack を `grep -n 'sed -n' file` にしたところ、式を継続行へ折り返すだけで走査対象から外れた。さらに探し方が 0 件を返すと haystack が空になり、`assert_not_contains` が**無検査で PASS** する。対策は (a) haystack の非空を precondition として先に assert する、(b) 走査軸を「実装の形」ではなく「コメント以外の本文全体」のように壊れにくいものにする、(c) denylist の語彙を宣言した規範に対して網羅する (`\b` `\|` だけでは最も自然な書き換え形 `[A-Za-z]\+` が素通りする)。

3. **`assert_grep_in_section` に escape 付きパターンを渡すと assert が常に PASS する (実測)**: 同 helper は `awk -v start=... -v end=...` でパターンを渡すため、awk が `-v` 代入時にバックスラッシュを剥がす。`^> \*\*fail-safe` は `^> **fail-safe` へ化け、成立しない正規表現になって**範囲が EOF まで伸びる** (実測で 677 行が抽出された)。結果、範囲外にあるはずの行が「範囲内」で見つかり assert が通る。同 helper の caller は 11 suite・42 箇所あり、escape を含むパターンを渡しているものは同じ縮退を持つ。**mutation を当てて初めて発覚する**類の欠陥で、pin を書いた直後に「守りたい欠陥状態を再現して落ちるか」を確かめる習慣がないと素通りする。回避は ENVIRON 経由で渡すか、escape を必要としないパターンにするか、隣接性のような単純な述語を直接書くこと。

4. **`var=$(pipeline) || var=""` は `set -e` 非設定下では利得ゼロのリスク**: `pipefail` × 早期終了フィルタ (`grep -m1`) × 上流 `printf` の SIGPIPE(141) を「不一致」と融合し、**捕捉に成功した値を破棄する**。同一ファイル内の sibling が `|| var=""` なしで書いているなら、その 1 行だけが house pattern から外れている合図。早期終了が要らないなら `head -1` に替えると SIGPIPE 経路自体が消える。

5. **診断へ外部入力を埋め込むときは canonical idiom を必ず通す**: 長さ上限 → CR 除去 → 改行畳み → 制御文字中和。中和範囲は `--c0-only` (C0+DEL のみ) を選ぶと日本語本文の UTF-8 継続バイトを潰さない。リポジトリに既存の中和 helper があるなら inline 再実装せず source する (canonical helper bypass の回避)。

6. **伝播適用の可否は「同じ欠陥クラスか」ではなく「同じ修正が当たるか」で決める**: 前 cycle では契約 pin の過剰一致が 7 site にあったが、意図的に複製された 2 コピーは「一致 1」ではなく「各 section に 1 ずつ」が正しく、機械的な伝播は誤った assert を生むため見送った。今 cycle の「偽の前提が 3 site に残置」はどの site も同一の訂正が当たるため伝播適用した。**同じ欠陥クラスでも正しい修正が同一でないなら、伝播させずに個別の finding として残すほうが安全**。

7. **正規表現を緩めると受理集合だけでなく分類の境界も動く**: 「トークン全体を貪欲に取る」単純化で、記法 1 の未展開 placeholder は absent のまま、記法 2 の同じ placeholder は先頭記号が読み飛ばされて invalid へ移った。reason が効果計測の分母を数える観測値である場合、同一の記入漏れが 2 つの reason へ分裂すると集計の意味が壊れる。読み飛ばしクラスから `{` `<` を除く 1 文字クラスの変更で閉じた。
