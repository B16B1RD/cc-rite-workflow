### Fix Patterns

1. **生成コマンドの結果を次のコマンドへ渡す前に exit status を検査する。特にリダイレクト先が既存ファイルのとき**。シェルはリダイレクトをコマンドの実行より先に評価するため、生成が失敗して空の値が渡ると、消費側が即死する前に出力先が truncate される。同じファイルを扱う別の書き手が一時ファイルと mv で書いているなら、その手順に揃えるのが最小の修正になる。

2. **成功 marker の値を command substitution から取るときは、その substitution が失敗した場合の見え方を確認する**。空の結果からフォーマットすると 0 が入り、壊れた状態のまま成功を名乗る出力になる。
