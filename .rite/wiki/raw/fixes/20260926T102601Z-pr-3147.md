### Fix Patterns
- cd 追跡の誤判定 3 形（演算子直後の改行、リスト先頭の ( ) グループ、& で終わるリスト）は、判定側ではなく解析器が返すリスト境界が bash と食い違っていたことが共通の根。判定に分岐を足さず、解析器の境界（空セグメントは継続演算子を保持、グループは外側リストに空コマンドを置く、& で終わるリストの cd は外へ伝播させない）を bash の意味に合わせて直した。
- 修正前のコードに同じ入力を通すと 6 形すべてが別リポジトリと解決され、修正後は target is dynamic で拒否されることを比較で確認した。対照（グループの後の ; で始まる確定的な cd、演算子直後で改行した && 連鎖の日常形）は従来どおり通る。
- 複合コマンド本体の cd（MEDIUM）とパイプ右辺のテスト固定（実測なし）は非 fatal として記録へ移した。
