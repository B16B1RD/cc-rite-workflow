### Fix Patterns

cycle 2 に続き、blocking の大半（6 件中 5 件）が前 cycle の修正自身に起因した。ただし型は変わり、今回は **「pin の観測経路」と「述語の受理集合」** に集中している。この 2 つは「修正が正しくても、その正しさを固定できていない」という共通の形をとる。

**1. 連言述語を pin する fixture は、項の数だけ用意する**

`A ∧ B` に negative control を 2 本置いても、両方が「A も B も false」なら**連言全体の削除しか検出できない**。片側だけを弱める変更（前方一致を部分一致へ、等値を包含へ）は素通りする。同じことが正規表現の 2 要素（行頭アンカーと空白許容）にも起きた。

再発防止: **連言を pin するときは「A のみ false」「B のみ false」の fixture を項の数だけ作る**。位置固定を持つ述語（前方一致 / 最終行の等値）では、さらに「値は含むが位置が違う」形が要る — 位置固定を外す変更はそれでしか落ちない。

**2. negative control は「到達したうえで発火しない」を確認する**

「誤検出しないこと」を assert する TC が、fixture の都合で目的の分岐へ一度も到達していないケースが 2 件あった。正規の入力を併記した fixture では前段の判定が成功してしまい、検証したい分岐に入らない。assert は常に真になり識別力はゼロ。

再発防止: **negative control の fixture は、検証したい分岐に確実に入る形にする**（前段が成功する要素を併記しない）。追加時に対応する mutation を当て、落ちなければ到達していないと判断する。

**3. 派生した述語は、元の述語との受理集合の関係を先に決めて 1 本から導出する**

厳格化した判定式と対で緩い検出式を足したところ、検出式の受理集合が処理式より広くなった。差集合の入力は「異常」と判定されるのに処理できず、「異常を検出したのに直せない」= 案内文が偽になる状態が生まれた。

再発防止: **同じ対象に対する複数の正規表現は、受理集合の包含関係を決めて 1 つの定義から導出する**。別々の文字列リテラルとして並ぶと、片方だけを触った編集で関係が崩れる。

**4. `set -o pipefail` 下で早期 exit する consumer をパイプ終端に置かない**

`... | grep -q .` は最初の一致で exit して上流に SIGPIPE を送るため、pipefail がパイプライン rc を 141 にする。「一致があった」のに偽が返る。入力が小さいと上流が先に書き終わるため発火せず、**出力が stdio バッファ境界を超えた地点で挙動が反転する**（小さな入力でのテストでは絶対に見つからない）。

再発防止: **真偽判定なら出力を最後まで読む形（コマンド置換の結果が非空かを見る）にする**。`grep -q` / `head` / `tail -1` をパイプ終端に置くのは、rc を見ない用途に限る。

**5. 静的 pin は表記の denylist ではなく意味の allowlist で書く**

「変数が `local` 宣言に含まれていないこと」を pin したが、`declare` / `typeset` も同じスコープを作る。表記を替えるだけで pin を通過したまま欠陥を再導入できた。

再発防止: **禁止したい表記を列挙するのではなく、成立させたい性質を書く**。等価な代替構文を allowlist として並べるか、より強く「定義位置が関数の外側であること」のような位置不変条件を固定する。

### 手法として効いたもの

- **mutation は意味だけを弱める形で書く**: 括弧の対応を崩す変異は FAIL 数が跳ね上がる（今回は 31）が、それは構文エラーが全 TC を巻き込んだだけで、意味的な弱化が検出されている証拠にはならない。実行ログに構文エラーが 0 件であることを確認したうえで FAIL 数を読む。
- **実測必須ゲートが LLM の転記ミスを捕捉した**: reviewer の実測アンカーを統合 JSON へ書き写す際 `=>` を落とし、ゲートが `anchor_unparseable` として降格を検出した。人間・LLM どちらの転記でも起きうる欠落を、ゲートが構造的に拾っている。
- **cross-validation が pin の穴に効いた**: 同じ述語の pin 不足を、2 人の reviewer が別々の mutation 軸（conjunct 削除 / 位置固定の弱化）で独立に検出した。片方だけでは片側の mutant が残っていた。
