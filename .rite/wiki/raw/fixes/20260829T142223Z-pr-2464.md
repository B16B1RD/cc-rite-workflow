### Fix Patterns

**pin literal を変えたら、その pin を説明している真上のコメントも同じ diff で追随させる**。contract test の grep pin は literal 自体を守るが、「なぜこの needle なのか」を説明する散文には守り手がいない。needle を `記法 1 優先` から `明示宣言 > 表行の優先` へ変えた際に、2 行上の説明コメントが旧 semantics のまま残り、次に探索順を触る作業者が最初に読む位置で誤った意図を伝える状態になっていた。本 PR 自身が「散文の pin が消えると探索順が逆順へ戻されうる」ことを設計根拠にしているので、その pin の説明文のずれは同じ失敗モードの入口になる。

この形の drift は **実測アンカーを構造的に持てない**（散文の記述内容であって実行時挙動を伴わない）ため実測必須ゲートで non-blocking へ降格し、`[review:mergeable]` 到達後の NB digest sweep で消化された。**アンカーを持てない指摘を「だから直さない」ではなく「blocking にしないが必ず消化する」経路へ流す**設計が機能した例。
