### Fix Patterns
- 失敗を終了コードで返すだけでは、stderr の文面で判定する完了レポートには載らない。レポートの行を WARNING の文面で判定する設計では、報告したい失敗経路（ここでは own のあとの解放失敗）ごとに WARNING を出し、終了コードは `cmd || { rc=$?; echo WARNING >&2; exit "$rc"; }` で保ったまま返す。
- 「なし」行の条件を「WARNING を出していない」にしておくと、新しい失敗経路に WARNING を足すだけで「なし」の誤判定も同時に閉じる。
- 特定の外部コマンドだけを失敗させる fixture は、必要なコマンドを symlink した PATH スタブに失敗する stub を 1 つ置く形が root でも効き、chmod より壊れにくい。
