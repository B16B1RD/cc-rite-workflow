# PR #3902 の修正結果（cycle 3）

- 指摘: テストに足した不正なバイトを含む名前は macOS のファイルシステムが Illegal byte sequence で拒否し、件数・行全体一致・後片付けが連鎖して落ちた。unquote のコメントは不正なバイトが 8 進で届くと書いたが、core.quotePath=false の git は 0x80 以上のバイトを生で出す
- 対応: UTF-8 ロケールを locale -a で選び、名前を書き込めるかを試して、そろうときだけその名前を足す。そろわなければ skip を表示する。コメントを git の実際の出力に戻した
- 学び: OS によって作れない fixture は、OS 名ではなく実際に作れるかを試して決め、外したことを表示する。入力の形をコメントに書くときは、固定した設定で実物を od で見てから書く
