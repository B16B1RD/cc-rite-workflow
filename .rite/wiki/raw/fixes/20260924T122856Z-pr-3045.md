# fix 結果: 起票前確認の判定結果を helper と marker に結ぶ手順をテストで固定する

## 対応した指摘

- test / HIGH: 判定結果（skip / ask）を helper のオプションと marker に結ぶ手順書の行が固定されていなかった
- prompt / LOW-MEDIUM: 完了報告の見送り付記に、placeholder の出所を説明する内部注記が混入した

## 修正

ask / skip / 起票する / 起票しない の 4 行を固定する assert を足し、各行を書き換える変異がすべて検出されることを確かめた。付記は利用者向けの文面に戻し、出所は表の後の散文へ移した。

## 知見

- 判定ロジックを抽出して実行するテストと、判定結果を後段の処理へ渡す行の固定は別物である。判定が正しくても、結果を使う側の行が書き換わると不具合は再発する。判定・受け渡し・記録の各段にそれぞれ変異をかけ、どの段もテストで検出されることを確かめる。
- 利用者に出す文面のテンプレート（表のセル）に、置換規則の説明を書き込まない。字義どおり展開すると説明文ごと表示される。出所の説明はテンプレートの外に書く。
