### Fix Patterns
- bash テストで Markdown の見出しから fence / 段落を切り出すとき、見出し文字列を `awk -v` で渡して `$0 == h` で照合すると、日本語見出しが macOS 標準 awk で別行に一致する。修正は見出しを `grep -nxF` で行番号へ解決し、awk には `NR == n` の整数だけを渡す形に置き換えた。あわせて一致数が 1 でなければその場で fail させ、「未一致なら空文字を返して下流 assert が別原因を名乗る」経路を塞いだ。文字列比較を跨プラットフォームで行う箇所は、比較そのものを bash/grep のバイト比較へ寄せ、awk には数値だけを渡す。
- 修正の検証は Linux ローカルの再実行では macOS 側の欠陥を再現できない。CI ログの失敗行を `failing_test` アンカーとして受け取り、修正後は CI の macOS leg の結果で確認する。
