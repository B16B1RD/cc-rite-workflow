### Fix Patterns
- run をまたいで持ち越す識別子は、「今回の単位」と「前の run の単位」の対応が 1 対 1 のときだけ安全に使える。多対 1（束ね）と 1 対多（分け）の両方向を同じ規則で止め、停止メッセージに要素ごとの前の識別子を出して、回復の手がかりにする。
- 機械が止める規則は、入力を書く側（分類役の手順）にも同じ語彙で書き、既存の優先規則（1 根因 = 1 記録）との優先関係を明示する。止まった run の出力から再開する手順があるなら、その出力を直してから再開するよう書く。
- 停滞診断が方針見直しを求めたときは、局所修正を重ねる前に不変条件を言語化し、代替案（別 key を振る・要素ごとの印）を比較してから最小の変更を選ぶ。
