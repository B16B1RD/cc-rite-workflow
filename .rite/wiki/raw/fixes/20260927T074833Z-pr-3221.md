# 修正パターン: 戻り方の手順は診断の範囲ではなく入力全体を対象に書く

- 失敗時の診断が先頭 N 行しか示さないとき、戻り方を「診断に出た行を直す」と書くと N 行を超える不正で空回りする。直す対象は入力全体（全行が同じ値を持つ列なら全行を確かめる）として書く。
- 案内の対象を理由名の接頭辞で絞ると、同じ段で別の理由を出す停止が漏れる。対象は手順の段（どの工程の後で止まったか）で表し、再実行の禁止には解除条件（どこまで終えたらよいか）を付ける。
- 見直し計画が固定された cycle では base 取り込みグループを足せない。base 差分だけで落ちる検証は、失敗がその差分だけであることを検査する形で通し、取り込みは次の cycle に回す。
