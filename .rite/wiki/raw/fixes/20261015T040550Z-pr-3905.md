### Fix Patterns
- 手順書のシェル実行形が数え上げに特定実装（procps の ps -L）を使う場合、数え上げ結果を検証せずに使うと他環境で黙って誤った上限に落ちる。検証していない環境向けの代替コマンドを書き足すのではなく、「結果が正の整数でなければ実行せず Measurement-Blocked として止まる」という fail-loud の一文で対応した（最小差分・推測で手順を増やさない）。
- 規則行を行全体一致で固定しているテストは、規則の文を変えたら定数も同じ文に揃える必要がある（同一 commit で両方を更新）。
- 検出網の精度だけに関わる class B の指摘（ロケール依存の否定 assert、負例 control のラベル照合不足）は fix 対象外として non-blocking に記録された。
