### Fix Patterns
- 操作後の読み直しは、操作と同じ ID を読む限り「操作が効いたか」しか確かめられない。ID 自体の取り違えを検出するには、上流とは独立した情報源（この場合は PR 本文の closing keyword とブランチ名）との照合を操作の前に置く。
- 照合は「既に完了済みか」の判定より前に置く。後に置くと、取り違えた ID の対象が既に完了済みのとき成功扱いで素通りする。
- 失敗時の手動回復案内は、取り違えの可能性がある ID をそのまま使わせない（正しい対象を確かめる手順を案内する）。
