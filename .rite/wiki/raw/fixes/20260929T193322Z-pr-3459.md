### Fix Patterns
- 冪等化の key を毎 run 入力から作り直すと、その材料を同じ run が書き直す状態（hold 等）から取った瞬間に、次の run で材料が変わって key がずれる。一度付けた key を、run をまたいで持ち越す既存のファイル（ここでは tracker 番号を持ち越す判定記録ファイル）に候補ごとに保存し、次の run では再利用する。
- 持ち越した key は判定の出口ごとに分けて持つ。出口が変わった再実行まで同じ key を使うと、新しい判定の書き込みを書き込み済みとして飛ばしてしまう。
- 前の run で別々の key を持った候補を 1 記録にまとめられたら、どちらの印で照合するかを決められない。黙ってどちらかを選ばず、書かずに止める。
- テスト helper が呼び出しのたびに状態を消していると、run をまたぐ状態の変化を観測できない。「新規開始」と「前の run の状態のまま再実行」の helper を分け、再実行を 2 回以上つないで key の一致を固定する。
