# PR #3902 の修正結果（PR 内推奨 1 件、cycle 4）

- 指摘: 不正なバイトを含む名前のケースを外す skip が echo だけで集計に出ず、理由も区別しないため、検査が必ず走るべき Linux でも LC_ALL=C を守る唯一のケースが黙って外れうる
- 対応: skip の理由をロケールの欠如と書き込みの失敗（エラーの 1 行目）に分けて表示し、Linux では skip せず fail にした
- 学び: 環境で前提を作れないケースを skip するときは、その検査が必ず走るべき環境を決めて、そこでは失敗にする。skip の理由は原因ごとに分けて出す
