### 中和の pin は「隣の未中和行」に邪魔される

中和の regression test を書くとき、素朴な「column 0 に偽 `WARNING:` 行がない」という形は **現状でも FAIL する**。同一実行の数行前に pre-existing の未中和 WARNING があり、同じ入力から column 0 の行を作るためである。assert は**自分が中和した行に限定**する必要があった（メッセージ末尾のリテラルで grep を絞る）。

**教訓**: 部分的に中和した経路に対する assert は、中和済みの行だけを対象にする。全体を見る形にすると、未中和の隣接行が常に混ざって assert が最初から赤いか、逆に緩めすぎて何も検出しなくなる。
