### Fix Patterns
- 仕様改訂をまたぐ受入条件の進展比較は、区間の最初の観測を基準にすると、その観測が修正後 HEAD 上にある経路で実際の進展を捨てる。改訂で追加された受入条件 ID を記録し、進展からその ID だけを除く規則のほうが経路に依らない。
- 「既に記録済み」を案内する条件は、context の一致だけでなく照合した本文と記録本文の一致まで確かめる。
- Python モジュールの単独 "," 定数は pyc に `,)` として残り、__pycache__ を走査するテキスト検査の残骸パターンに一致しうる。テストが __pycache__ を走査する間は、単独の "," 定数を避けるか、検査側で __pycache__ を除外する。
- verify の入力にディレクトリを指定する場合、テスト実行で生成される __pycache__ が入力を変えるため、事前に一度テストを走らせてから verify する。
