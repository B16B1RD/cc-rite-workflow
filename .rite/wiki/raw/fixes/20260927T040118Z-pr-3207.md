# 修正パターン: 共有 ref の判別子は「除外すべき集合」で定義する

- 対象: レビュー後の状態検査（stash / branch_list 軸）
- 問題: 並列セッションの操作を除くため「自 worktree に帰属するものだけを数える」と定義したところ、reviewer 自身が別 worktree・別 branch を経由した操作まで除外され、改修前に検出できていた違反が見えなくなった。
- 修正: 除外する集合を「他セッションの worktree で checkout 中の branch」と明示し、branch_list はその branch を、stash は件名の branch がそれに当たるものを除く。reviewer 実験用 worktree の名前空間は他セッションに数えない。
- 経験則: 「残すもの」ではなく「除外すべきもの」で判別子を定義すると、除外の意図外の操作が数え続けられる。改修前の helper と同じ操作で結果を比べ、検出が失われていないか確かめる。
