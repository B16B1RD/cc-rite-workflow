# PR #3896 の修正結果（cycle 3）

- 対象の指摘: number-reference-check がファイル名を awk -v で渡し、バックスラッシュを含む名前がエスケープとして解釈されて表示名と件数が崩れる
- 修正: 名前を環境変数で渡して ENVIRON で読む。テストの奇妙な名前にリテラルのバックスラッシュを含む名前を追加
- 検証: awk -v に戻す変異で表示と件数の 2 件が失敗。停滞診断が replan を返したため、代替案 3 つ（ENVIRON / bash で前置き / 除外）を記録して ENVIRON を選んだ
- 学び: 生の名前を NUL 区切りで受けても、名前が通る次の境界（awk -v など）で再びエスケープ解釈されうる。受け渡しは全境界で生のまま渡る形にそろえる
