# 日本語文書の記号規定

rite が日本語の文書を書くときの、記号の字形を定める。規定の正本はこのファイルだけに置き、各手順にはこのファイルを読む 1 行のポインタだけを置く。

## 適用範囲

- 新しく書く行と改訂する行だけに適用する。既存の行は規定に合わせて書き換えない。差分に字形だけの変更を混ぜない。
- 出力が日本語である文書の、日本語を含む行に適用する。対象は Issue・PR の本文、コミットメッセージ、日本語の変更履歴、Issue ごとの作業記録の散文、rite 自身の手順書の日本語の行。
- `language: en` の設定、英語の文書、英日ペアの英語側、日本語を含まない行には適用しない。`language: auto` のときも、実際に英語で出力した文書は対象外とする。
- hooks などが固定の文字列で生成する行（作業記録の初期化時のラベル行など）は変えない。ラベル行の読み取りは半角コロンと全角コロンの両方を受け付けるため、書く側の字形がどちらでも動く。

## 字形表

日本語を含む文の中では、次の表の右の字形で書く。

| 記号 | 書かない字形 | 書く字形 | 備考 |
|------|--------------|----------|------|
| 中点 | `･`（U+FF65）、`·`（U+00B7） | `・`（U+30FB） | 語の並列の区切り |
| スラッシュ | `/` | `／`（U+FF0F） | 日本語の文中で語を並べる用法だけ。パス・URL・分数・日付は半角のまま |
| コロン | `:` | `：`（U+FF1A） | 日本語の説明やラベルの区切り。半角のまま残す場所に挙げた行は除く |
| 波形 | `~`、`～`（U+FF5E） | `〜`（U+301C） | 範囲やおおよその値。U+FF5E は使わない |
| 三点リーダー | `...` | `…`（U+2026） | 文の省略 |
| 丸括弧 | `(` と `)` | `（` と `）`（U+FF08、U+FF09） | 補足や言い換え |
| かぎ括弧 | `｢` と `｣`（U+FF62、U+FF63） | `「` と `」`（U+300C、U+300D） | 語句の引用や強調 |
| 二重かぎ括弧 | かぎ括弧の入れ子（`「「…」」`）、入れ子の `"…"` | `『` と `』`（U+300E、U+300F） | かぎ括弧の中の引用、作品名 |
| 角括弧 | `[` と `]` | `［` と `］`（U+FF3B、U+FF3D） | 文中の補足の記号。Markdown のリンクとチェックボックスは半角のまま |
| 引用符 | `"…"`、`'…'`、`“…”` | `「…」` | 入れ子は `『…』` |

## 半角のまま残す場所

次は日本語を含む行の中でも半角のまま書く。

- コードスパン・コードフェンスの中
- URL、ファイルパス、ブランチ名、コマンド、識別子、設定キー
- Markdown の構文記号（見出し・箇条書き・番号付きリスト・リンクの角括弧と丸括弧・チェックボックス・表の区切り・強調）
- HTML とそのコメント
- frontmatter など機械が読むキーと値の構文
- Conventional Commits の件名の `type(scope):` の部分（件名の説明文には規定を適用する）
- コミットメッセージのトレーラー（`Co-Authored-By:` など）と、スクリプトが生成または解析する定型行（作業記録の `Phase:` と `Branch:` の行など）
- 検査が字面を固定しているラベル（上段要約の用語欄の見出し `**用語**:` だけ。用語欄の項目行は固定されていないので、規定に従い全角で書く）

数字と英字は全角にしない。`10〜20` や `SKILL.md` のように半角で書く。

## ラベルの区切り方

箇条書きの見出し語（ラベル）と説明は、全角コロンで区切る。句点では区切らない。太字のラベルは `- **ラベル**：説明` の形で書き、コロンの直後に空白を置かない。太字かどうかに依らず同じ規則で、半角のまま残す場所に挙げた行だけが例外である。

## 例と矯正例

規定外の例：

```
- **対象**: 手順書(3 本)/参考資料(2 本)
- **件数**: 10 ~ 20 件...
- **理由**。"既存の行" は変えない
```

矯正例：

```
- **対象**：手順書（3 本）／参考資料（2 本）
- **件数**：10〜20 件…
- **理由**：「既存の行」は変えない
```
